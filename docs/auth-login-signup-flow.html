소셜 로그인 (NextAuth)

OAuth는 NextAuth가 처리합니다. 콜백의 signIn에서 provider access_token을 user-service 소셜 로그인으로 넘깁니다.

소셜 버튼google / kakao / naver
↓
제공자 동의NextAuth OAuth
↓
/api/auth/callback
↓
account.access_token
↓
Gateway/api/user/api/v1/auth/login/social/{p}
↓
기존 회원 200JWT → /home
신규 422SOCIAL_003 → /signup/social-terms
401경로 오류 또는 SOCIAL_002
최근 401의 실제 원인 Google/Kakao 콜백(302)은 성공했습니다. 앱이 Gateway 없이 /api/v1/auth/login/social/google 을 쳐 빈 401이 났습니다. 올바른 전체 경로는 /api/user/api/v1/auth/login/social/{provider} 입니다.

소셜 신규 가입 갭

422 시 provider만 쿼리로 넘기고 accessToken은 버려집니다. SocialSignupTermsTemplate는 안내 문구만 있고 termsAgreements를 다시 보내지 않습니다.

소셜 로그인POST /api/user/api/v1/auth/login/social/{provider}
로컬 가입POST /api/user/api/v1/auth/signup/local
